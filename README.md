# DownMaster - Universal Social Media Downloader

DownMaster is a fast, full-featured video, audio, and thumbnail downloader for YouTube, TikTok, Instagram, Twitter, and Facebook.

Built with React, Node.js, Express, yt-dlp, and FFmpeg.
